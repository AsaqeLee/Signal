# 调制信号分类项目

本项目实现了一个基于深度学习的调制信号分类系统，可以识别10种不同的调制类型并预测码元宽度。

## 输入数据说明

1. 数据格式
   - CSV文件，每个文件包含单个信号样本
   - 文件结构（5列）：
     - 第1列：I路数据（实部）
     - 第2列：Q路数据（虚部）
     - 第3列：码序列（可能包含NaN值）
     - 第4列：调制类型（1-10的整数）
     - 第5列：码元宽度（浮点数，单位：微秒）

2. 采样要求
   - 采样率：20MHz（每微秒20个采样点）
   - 每个码元的采样点数 = 码元宽度 × 20
   - 例如：码元宽度为0.5微秒时，每个码元包含10个采样点

3. 数据特征
   - I/Q数据：浮点数，表示信号的同相和正交分量
   - 码序列：整数，表示调制后的数字序列
   - 调制类型：1-10分别对应不同的调制方式
   - 码元宽度：通常在0.1-1.0微秒范围内

4. 数据预处理
   - I/Q数据归一化：减均值除标准差
   - 序列填充：所有样本填充到相同长度
   - 无效值处理：移除包含NaN的码序列部分
   - 长度调整：保持码元完整性的前提下截断或填充

## 功能特点

- 支持10种调制类型的识别：
  - BPSK
  - QPSK
  - 8PSK
  - MSK
  - 8QAM
  - 16QAM
  - 32QAM
  - 8APSK
  - 16APSK
  - 32APSK

- 码元宽度预测
  - 相对误差在±5%以内
  - 提供详细的误差统计信息

## 数据处理

1. 数据筛选
   - 验证IQ数据完整性
   - 检查码序列有效性
   - 验证码元宽度
   - 确保采样点数匹配

2. 数据预处理
   - IQ数据归一化
   - 序列长度统一
   - 保持码元完整性
   - 去除无效样本

## 模型结构

1. 特征提取
   - 多层卷积网络
   - 批归一化
   - Dropout正则化
   - 自适应池化

2. 分类头
   - 调制类型分类（10类）
   - 码元宽度预测（回归）

## 训练策略

1. 数据集划分
   - 训练集：80%
   - 验证集：20%
   - 每类保持样本数量平衡

2. 优化方法
   - Adam优化器
   - 学习率自适应调整
   - 早停策略
   - 模型检查点保存

3. 评估指标
   - 调制类型准确率
   - 码元宽度相对误差（±5%）
   - 综合评分（调制类型40%，码元宽度60%）
