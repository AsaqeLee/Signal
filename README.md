# 调制信号分类项目

本项目实现了一个基于深度学习的调制信号分类系统，可以识别10种不同的调制类型并预测码元宽度。项目特别优化了训练过程，支持断点续训，适合在有环境噪声干扰的情况下使用。

## 特性

1. **断点续训**
   - 支持单轮训练模式
   - 完整的状态保存和恢复
   - 训练过程可随时暂停和继续
   - 适合在有环境噪声的情况下使用

2. **性能优化**
   - 自动混合精度(AMP)训练
   - 梯度累积和梯度裁剪
   - 多种学习率调度策略
   - 标签平滑和数据增强

3. **训练稳定性**
   - 完整的错误处理
   - 自动资源清理
   - 早停机制
   - 详细的日志记录

4. **模型特点**
   - 支持10种调制类型识别
   - 码元宽度预测
   - 残差连接
   - 注意力机制

## 快速开始

1. **环境准备**
   ```bash
   pip install -r project/requirements.txt
   ```

2. **数据准备**
   - 将原始数据放在 `train_data` 目录
   - 运行数据筛选：
     ```bash
     python project/data_filter.py
     ```

3. **训练模型**
   - 单轮训练：
     ```bash
     python project/train_modulation.py
     ```
   - 每次运行将：
     - 训练一个epoch
     - 保存训练状态
     - 进行验证
     - 自动清理资源
   - 重复运行以继续训练

4. **检查训练状态**
   - 查看 `checkpoints/training_state.json`
   - 检查 `logs` 目录中的日志文件

## 训练策略

1. **断点续训机制**
   - 每轮训练后自动保存状态
   - 支持随时中断和继续
   - 保存最佳模型
   - 训练状态完整记录

2. **优化策略**
   - 自动混合精度训练
   - 梯度累积（默认8步）
   - 梯度裁剪（阈值1.0）
   - 多种学习率调度
   - 早停机制（15轮无改善）

3. **数据增强**
   - Mixup (alpha=0.2)
   - CutMix (alpha=1.0)
   - 标签平滑 (epsilon=0.1)

4. **资源管理**
   - 自动限制CPU核心使用
   - 内存使用优化
   - GPU内存管理
   - 及时资源释放

## 性能指标

1. **评估指标**
   - 调制类型准确率（权重0.4）
   - 码元宽度相对误差（权重0.6）
   - 综合评分

2. **训练监控**
   - 实时损失曲线
   - 验证准确率
   - 资源使用情况
   - 训练时间统计

## 注意事项

1. **训练建议**
   - 建议每次只训练一轮，观察结果
   - 在环境噪声较大时暂停训练
   - 定期检查验证准确率
   - 注意早停提示

2. **资源使用**
   - 默认限制使用2个CPU核心
   - 限制内存使用为8GB
   - 可在config.py中调整资源限制

3. **数据要求**
   - 确保数据格式正确
   - 运行数据筛选去除异常样本
   - 保持数据集平衡

## 常见问题

1. **导入错误**
   - 确保在项目根目录运行脚本
   - 检查Python路径设置
   - 验证依赖包安装

2. **内存问题**
   - 调整batch_size
   - 减少工作进程数
   - 检查数据预加载设置

3. **训练中断**
   - 训练状态会自动保存
   - 直接重新运行即可继续
   - 检查日志文件了解中断原因
